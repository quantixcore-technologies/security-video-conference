(ML-стек, anti-capture, LiveKit/E2EE, desktop-фреймворк), 8 эпик-спеков, security-доки.

**E2 Посещаемость:** ростер, attendance_records (статусы present/late/left_early/absent),
Oban FinalizeWorker, Recordings (Egress-сущность), журнал-UI (RBAC-scoped).

**Полировка + редизайн «Secure Operations»:** тёмная slate-тема + emerald-акцент,

totp_secret шифрование at-rest (Cloak), редизайн всех 8 страниц.

## 🎬 Доказано вживую (в браузере)

## 🐉 Боссы добиты (root-fix + TDD, не костыли)

1. protobuf 0.14 не компилится на Elixir 1.19/OTP 28 → override 0.16.1.
2. brew-postgres@17 воровал порт 5432 → docker на 5434 (DB_PORT env).
3. Oban требует v14 (не 12).
4. macOS localhost → IPv6, docker IPv4 → hostname 127.0.0.1.
5. HEEx НЕ интерполирует `{}` внутри `<script>` → `<%= %>`.
6. livekitex webhook: ждёт «Bearer», iss хардкод «webhook» → TokenVerifier с api_key напрямую.
7. LiveKit JS v2: `setCameraEnabled` (не `enableCameraAndMicrophone`).
8. chrome-devtools MCP браузер = «automated test software», БЕЗ камеры (NotAllowedError)
   и media DTLS timeout — не годится как реальный участник, нужен обычный Chrome.
9. + десятки граничных случаев (FK, валидации длины, unused helpers) — пойманы TDD.

## 🚀 Как запустить локально

```bash
docker compose -f deploy/livekit/docker-compose.yml up -d   # LiveKit :7880
docker run -d --name svc-postgres -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_USER=postgres -p 5434:5432 postgres:16        # Postgres :5434
DB_PORT=5434 mix ecto.setup && DB_PORT=5434 mix run apps/svc/priv/repo/seeds.exs
DB_PORT=5434 mix phx.server                                  # http://localhost:4000
# Вход: admin / AdminPass12345 (super_admin). Все seed-юзеры: AdminPass12345.
```

Звонок: войти → Встречи → планёрка → «Войти в звонок» (разрешить камеру в обычном Chrome).
