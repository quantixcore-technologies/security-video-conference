## 🟥 БЛОК 1 — E4 «CRM + Kanban» (самый размытый, блокирует весь эпик)

> «CRM» для гос-ведомства — это НЕ продажи. Нужно понять реальный смысл. Без этого строить нельзя.

1. **Что такое «CRM» в вашем контексте?** Выберите/уточните:
   - ☐ Обращения граждан (заявки, жалобы, запросы) с трекингом статуса
   - ☐ Поручения руководства (кто кому что поручил, дедлайн, исполнение)
   - ☐ Задачи сотрудникам (внутренний task-management)
   - ☐ Учёт контактов внешних организаций/контрагентов
   - ☐ Что-то другое: ______
2. **Kanban-доска — для чего конкретно?** (задачи по статусам / обращения / поручения / проекты?)
3. **Кто пользователи?** (все сотрудники · только руководители · конкретный отдел · диспетчер?)
4. **Связь с конференциями/посещаемостью?** (поручения по итогам совещаний? задачи из встреч?)
5. **Карточка (обращение/задача) — какие поля?** (заявитель, тема, описание, приоритет, исполнитель, срок, статус, вложения, история?)
6. **Workflow:** создание → назначение → в работе → проверка → закрыто? Кто на каком шаге?
7. **Приоритеты / дедлайны / эскалация** просроченных — нужны?
8. **Отчётность:** статистика выполнения (по исполнителю/отделу/срокам)?
9. **Дайте 1–2 реальных кейса** «как сотрудник это использует за день».

> _После ответов → разбиваем E4 на конкретные слайсы (Kanban-доска, карточки, workflow, отчёты)._

## 🟩 БЛОК 4 — E7 сеть/гео (MMDB + политика)

> Pre-join gate + гео-политика per-org готовы (архитектура). Реальный детект требует:

1. **MaxMind-лицензия** одобрена (GeoIP2 Country + Anonymous IP), или бесплатный GeoLite2 (ниже точность)?
2. **Allowed-countries:** только UZ, или есть легитимные удалённые (командировки/диппредставительства)?
3. **Whitelist:** известны корп.прокси/ASN/диапазоны ведомства (против false-positive)?
4. **Режим по умолчанию:** жёсткий block при VPN/вне-страны, или flag-only + решение Security Officer?
5. **GPS на mobile** — принудительно (require_gps) или опционально (privacy/UX)?
