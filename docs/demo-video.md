## Как переснять веб-сцены

1. Поднять локально dev-сервер и демо-организацию с теми же именами, что в кадре
   (`Aziz Karimov — Rahbar`, `Dilnoza Yusupova — Xodim`, `Sardor Aliyev — Xavfsizlik ofitseri`),
   локаль — **английская** (остальное видео на английском).
2. Писать через CDP (`Page.captureScreenshot` по таймеру ~8 кадров/с) с
   `Emulation.setDeviceMetricsOverride` **1920×1080** — иначе кадр будет 1920×993
   и не сойдётся с остальным видео.
3. Собрать кусок, нарезать `.ts` с одинаковыми параметрами и склеить
   `concat:` — в конце добавить тихую дорожку (`anullsrc`).

## Как переснять сцены с телефона

Экран приложения **не записывается**: `FLAG_SECURE` (E5, D-013) отдаёт чёрный кадр
и на эмуляторе тоже. Для съёмки собирается **отдельный билд только для записи**:

```
# ВРЕМЕННО, не коммитить:
#   MainActivity: убрать window.addFlags(FLAG_SECURE)
#   SERVER_URL → http://10.0.2.2:4010  (в MainActivity и NotifyWorker)
./gradlew :app:assembleDebug && adb install -r -g app/build/outputs/apk/debug/app-debug.apk
# сразу после сборки вернуть оба файла из бэкапа и проверить:
grep -c FLAG_SECURE .../MainActivity.kt   # 1
grep -c admin.co1nlist.uz .../MainActivity.kt .../NotifyWorker.kt   # по 1
```

Съёмка: `adb shell screenrecord --bit-rate 10000000 --size 1080x2340 /sdcard/rec.mp4`,
управление — `adb shell input tap` по координатам (Compose-кнопки часто не видны
в `uiautomator dump`, поэтому координаты снимаются со скриншота).

**Две ловушки, на которых уже спотыкались:**
1. `input keyevent 4` (BACK) для закрытия клавиатуры — если клавиатуры нет, это
   выход из приложения. Проверять: `dumpsys input_method | grep mInputShown=true`.
2. `pm clear uz.svc` перед дублем сбрасывает сессию: дальше идёт хрупкий экран
   входа. Проще залогиниться заранее и снимать уже изнутри.

Композиция под стиль видео: фон-карточка 1920×1080 (текст слева) + запись экрана
телефона, масштабированная в **441×956** с позицией **x=1327, y=62**.

## Публикация

Cloudflare кэширует `svc-demo.mp4` на 4 часа, поэтому в `index.html` у ссылок стоит
версия (`?v=2026-09-22b`) — при замене видео её **обязательно** менять, иначе часть
зрителей увидит старый ролик.
