# UX/UI Audit — Security Video Conference

> Аудит 2026-06-05 (после редизайна «Secure Operations»). Честная оценка по фактам кода.
> Легенда приоритетов: **P0** — продукт функционально неполон · **P1** — заметный UX-разрыв · **P2** — полировка/масштаб.

## ✅ P0 — Функциональные дыры — ВСЕ ЗАКРЫТЫ (2026-06-05, Слайсы A/B/C, коммиты 36–38)

> 1 — управление сотрудниками (edit/deactivate/reset) · 2 — карточка `users/:id` ·
> 3 — управление встречами (edit/end) · 4 — 2FA enrollment (QR + подтверждение). +13 тестов.

| # | Gap (закрыт) | Факт | Почему критично |
|---|-----|------|-----------------|
| 1 | **Сотрудники: только создание** | `handle_event` = validate/save. Нет edit/deactivate/reset/delete | Админ-HR не может сменить роль/отдел/телефон, отключить уволенного, сбросить пароль. Управление персоналом мертво после создания. |
| 2 | **Нет карточки сотрудника** | Нет роута `users/:id`, клик по строке мёртв | Нельзя посмотреть профиль сотрудника, его посещаемость, фото. |
| 3 | **Встречи: только создание + журнал** | `Meetings.start/end_meeting` есть в контексте, **но UI нет** | Нельзя отменить, отредактировать, вручную завершить встречу, поправить ростер. |
| 4 | **2FA нельзя включить** | `setup_totp`/`confirm_totp` есть в backend, профиль показывает лишь статус | **Противоречие:** 2FA *обязательна* для админов (D-006 `totp_required?`), но enrollment-UI (QR + подтверждение) отсутствует. |

## 🟠 P1 — UX-состояния и навигация

| # | Gap | Деталь |
|---|-----|--------|
| 5 | **Mobile-навигация слабая** | На <lg только 3 иконки в topbar, sidebar скрыт. Нет бургер-меню, подписей, активного состояния. |
| 6 | **Нет loading-состояний** | При навигации/сохранении — пустота вместо skeleton/spinner. |
| 7 | **Нет confirmation-диалогов** | Когда появятся deactivate/delete — действия без подтверждения опасны. |
| 8 | **Login**: нет «показать пароль», нет пути восстановления | Для гос — вероятно сброс через админа, но это надо явно сказать пользователю. |
| 9 | **Смена пароля**: нет повтора нового пароля + нет индикатора силы | Опечатка в новом пароле → блокировка себя. |
| 10 | **first_name хрупок** | Предполагает «Фамилия Имя …»; есть fallback, но для иных форматов сломается. |
